#  Student Performance SQL Analysis

##  Project Overview
This project analyzes student performance using SQL to uncover insights about how lifestyle factors affect academic results.

---

## Business Questions
- What is the average exam score?
- How does study time affect performance?
- Does sleep duration impact results?
- Is there a relationship between physical activity and performance?

---

##  Key Insights

###  Overall Performance
- The average exam score is **67.24%**, indicating moderate performance.

### Study Time Impact
- Students who study more hours tend to achieve higher scores.
- There is a **positive correlation** between study time and performance.

###  Sleep Impact
- Students with balanced sleep perform better.
- Lack of sleep negatively affects performance.

###  Physical Activity
- Students with balanced lifestyles (including activity) perform better.

---

##  Dataset
- Columns include:
  - Hours Studied
  - Sleep Hours
  - Physical Activity
  - Exam Score
  - Extracurricular Activities
